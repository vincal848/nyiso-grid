## Conventions

- **Timestamps.** Every series is keyed on `ts_utc` = interval START in UTC. `ts_local` is the same instant in America/New_York for display. Daily rollups use local calendar days (23/25 hours on DST days).
- **Interval-ending stamps.** NYISO stamps real-time LBMP (realtime_*) and fuel mix at interval END; the parser shifts them to start (stamp − 5 min in the curated tables). Load, interface flows, constraints, DA and integrated hourly files are stamped at interval START.
- **Fall-back DST day.** Files with a Time Zone column (EDT/EST) are localized from it. Otherwise, per entity in file order, every row after local time steps backward (or repeats) is EST. 'First occurrence = EDT' is wrong: off-grid stamps in the EST hour (e.g. 01:02:48 on 2021-11-07) occur once. Regression test: tests/test_parse.py::test_offgrid_stamps_in_repeated_hour_are_est.
- **Irregular RTD intervals and time weighting.** ~4% of real-time intervals are not 5 minutes (delayed RTD runs publish stamps like 02:59:55). Curated tables keep stamps as published. Derived tables rebuild each interval's true [start, end) from the neighbouring stamp (gaps > 15 min are treated as missing data with a nominal 5-min interval) and time-weight onto 5-min/hourly buckets (store/timeweight.py). Verified: reproduces NYISO's integrated hourly RT LBMP to the cent in every hour 2021–2024. Averages over derived tables should weight by covered_s.
- **Price components.** LBMP = energy + mlc − mcc (verified: energy is identical across all zones in an interval). A negative mcc means congestion raises the local price.
- **Accepted data flags.** lbmp_zone_hourly.rt_flag marks hours where NYISO's integrated RT differs from its own 5-min data (2025-05-27 19:00–21:00: NYISO 5-min intervals missing; the latest hour at download time). Values are kept as published.
- **Known NYISO archive gaps.** rt_lbmp_node: 2026-08-01..26 missing (map falls back to hourly). rt_lbmp_zone_hourly: 2026-07-01..20 missing (filled, rt_source='derived_twa'). btm_solar: ~20 whole days missing. Full per-day detail: data/coverage.parquet.
- **Dashboard KPI definitions.** Price = simple average of the 11 internal zones' RT LBMP (not load-weighted; GridStatus uses a slightly different figure). Net load = load − wind. Main source = largest fuel at the selected interval.
- **Zone boundaries.** No openly licensed NYISO zone boundary file exists (NYPA's ArcGIS layer forbids redistribution). zones.geojson assigns Census counties to zones by majority vote of generator nodes, with overrides (Putnam→HUD VL, Livingston→GENESE, Westchester split at 41.13°N into MILLWD/DUNWOD). Approximate; drop an official file at data/ref/zones_override.geojson to replace it.
- **Node mapping.** Only generator nodes have coordinates. 561 of 758 priced nodes are mapped; the rest lack coordinates or are retired units absent from the current generator.csv.
- **As-of availability.** Forecast issue time for D+1 = 05:00 ET on D−1 (NYISO DAM bid deadline, MST 4.2; results post by 11:00). ISOLF file dated F is posted ~07:05–08:20 ET on F (MIS P-7 index), so it is usable from 08:30 ET on F: a 05:00 D−1 issue may only use the ISOLF file of D−2. DA prices for D−1 are known from 11:00 on D−2. RT data is known up to its interval end. Henry Hub for trade date T: 00:00 ET on T+1. Weather obs: hour + 30 min. Weather forecasts: see weather_fcst.available_utc. Outage schedules: first_seen_utc. External tables carry available_utc explicitly.
- **Licensing.** NYISO MIS, NOAA and EIA data are public. weather_fcst comes from Open-Meteo's free, non-commercial API and is for research/backtesting only; replace it with a licensed forecast source before any live trading use.
- **Units.** Prices $/MWh; power MW (MIS labels some flow/limit columns 'MWH' — they are interval rates in MW); shares are fractions 0–1.
